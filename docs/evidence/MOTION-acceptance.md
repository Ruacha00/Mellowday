# 前端动效与流畅度验证

2026-09-19，在 `8d47315` 前端交付基础上增加轻量动效，已更新日常 8021 的前端镜像。

## 实现

- 页面整体淡入 180ms，标题轻移 260ms；路由立即卸载旧页面，不等待退场，也不保留旧页面的请求与交互。
- 移动抽屉滑入/滑出 240ms，遮罩淡入/淡出 200ms；关闭时立即 inert，Escape 恢复焦点，切回桌面自动解除主内容禁用。
- 按钮、导航和主题卡片提供轻微悬停/按压反馈；精细悬停只用于鼠标等精确指针。
- 新对话消息进入时淡入并位移；历史装载不逐条播放，文字增量不重复触发动画。使用单条 Vue Transition，不用列表移动动画，避免每次增量测量整个列表。
- 仅回复进行中播放三个等待圆点；停止后移除。页面隐藏时暂停 CSS 动画，恢复可见后继续。
- 遵循系统 `prefers-reduced-motion`，减少动态效果模式关闭所有动画与过渡；静态提示和交互保留。

动画主要改变 opacity/transform；小控件的背景和边框颜色短暂过渡。不动画化宽高、页面边距、大图、模糊半径；移除抽屉遮罩的全屏模糊。不新增依赖、计时轮询或生产环境 requestAnimationFrame 循环，空闲时没有持续动画。

## 验证与实测限制

| 验证 | 结果 |
| --- | --- |
| `npm run test -- --run` | 40/40 |
| `npm run build` | 类型检查与生产构建通过 |
| 既有 Chromium 主流程，真实 Nginx + 隔离 fixture | 9/9 组 |
| 专项动效/焦点/可访问性/生命周期检查 | 5/5 组，0 页面异常 |
| 4 倍 CPU 降速，连续 10 次导航与流式回复 | 297 帧，帧间隔 P95 **16.8ms**；1 帧间隔 >50ms |
| 长任务观测 | 1 次，最长 **62ms** |
| 日常 HTTP/静态检查 | 10/10 |

性能门槛为采样帧间隔 P95 ≤50ms。浏览器在本机 headless Chromium 下测试生产构建，数据与模型均为隔离 fixture；4 倍 CPU 降速不是实际低端设备/GPU 测试，不能保证所有设备恒定 60fps。一次 62ms 长任务如实保留。空闲页面动画数为 0，稳定流式过程中只有 3 个圆点动画，停止后回到 0。页面隐藏的 listener 分支以模拟 visibilitychange 验证，不冒充操作系统后台调度测试。

原始数据、镜像身份及本轮文件哈希见 [MOTION-acceptance.json](raw/MOTION-acceptance.json)。前端最终镜像 config 为 `0d4905146389e59cde065f7e0c6085a01197e4d1e943d6496041d2f59c2ff4bc`；本次不修改 API、运行时或数据卷。

复现：先启动连接脚本化 fixture 的独立前端/API，然后执行：

