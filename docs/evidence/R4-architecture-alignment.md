## 范围与行为变化

1. 保留主对话循环、工具调度、provider 路由、上下文折叠、技能检索、候选提取→模型决策→确认→版本保存。源码对应审计只存本机内部记录。
2. 撤销全库事实与全部技能正文不重叠的不变式。相关事实可能是流程前提，不能凭文字相似度取代。普通事实即使与启用/停用技能相关也保留。
3. 迁移改为候选明确给出 source_memory_ids、确认展示 ID 与完整原文、成功写入后核对快照。未知 ID、拒绝、discard、写入失败及确认期间修改均不得误改事实。原记录保留。
4. 迁移后的旧对话内容不做模糊删除；复用既有失效追踪，在下一轮请求明确标为失效，当前召回段不再出现旧值。新会话停用规则的载荷门禁仍保留。
5. 合并仅作精确去重，旧规则默认保留，只有逐字 superseded_rules 才允许删除；数字与否定变化不再被相似度吞掉。最新用户轮决定临时/长期作用域。
6. 记忆工具显式 workflow 分类返回结构化拒绝并指向技能流程。fact/preference 不使用关键词猜测，因此模型误分类仍须实测，不能宣称确定性阻断全部错写。
7. 长结果页状态保留 ref，翻页与重新展开可读取；合法会话 ID 不再裁掉首尾连字符，防止 a/a- 的文件目录碰撞。管理页显示历史记录中“取代时已停用”状态。
8. 技能缓存按实际搜索目录区分，避免同一进程切换数据根后使用其他目录的技能。
9. 评测迁移判据检查来源与确认，不再以全库相似文字要求迁移；P5 聚合强制跨臂工作区指纹和模型配置一致。
10. 真实门禁发现并修复二次问题：迁移指令不再引导主模型先调用忘记工具；提取器对空响应、截断 JSON 和错误 schema 返回可见失败，合法空候选才表示无候选；学习响应预算由 2200 增为 4096。后者有真实失败响应回放回归，前者仍需真实模型验证遵循程度。
