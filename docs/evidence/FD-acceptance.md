## 已发现并解决的问题

- 容器包源下载出现 SSL EOF/ECONNRESET；使用宿主可达代理作为 Docker 构建参数后成功，未关闭 TLS 或保存代理凭据。
- Markdown 依赖发现安全公告，升级至 14.3.2；静态缓存探针发现 Nginx 正则优先级覆盖了 immutable，改用 `^~` 后通过。
- 停止后的迟到会话级 abort 可能误伤下一轮；前端改为只取消当前 POST reader。
- 配置 `max_turns` 原先不能清空，现支持显式 null；状态判定统一忽略大小写，匹配 Store。
- 最近会话慢请求原先覆盖后续导航；现在仅成功且仍拥有导航意图的请求跳转，失败显示错误。
- Skills 旧列表覆盖新状态已用失败测试复现，再通过请求版本隔离修复。
- 浏览器脚本曾使用错误角色/未展开详情/错误标题断言，按实际 DOM 与协议修正；镜像校验曾把基础层默认首页当最终首页，改为逐层扫描内容、按最终覆盖结果比对产物。

最终镜像扫描覆盖 API 12 层/23 条历史/12,832 个常规文件，前端 10 层/24 条历史/1,033 个常规文件。受限名称、两项本机实际凭据的原始/Base64 值及内部材料均零命中。检查不覆盖 Git 历史、BuildKit 未导出的中间缓存或任意编码后的未知凭据；运行环境中的合法凭据注入不属于镜像层。
