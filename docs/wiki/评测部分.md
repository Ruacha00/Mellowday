# MellowDay 评测与验收说明

本文保留“目标、样本、执行流程、指标、结果、折叠对照”的阅读顺序，所有结果以当前仓库证据为准。

## 数据集概览

当前评测分三层：程序行为的离线回归、真实 HTTP/浏览器集成、隔离数据下的真实模型对照。三者不能合并成一个成功率。

### 产品行为样本

记忆覆盖显式授权、自动确认、删除不重建、停止后不写入；人格覆盖当前证据、核心保护、规则注入和撤销；日历覆盖区间、重复、时区、补发、防重、未读与删除会话。

### 历史 P5 对照

关闭 Skill、固定 Skill、学习后 Skill 三臂，固定开发案例与不同数据的保留案例，每格 3 次，总计 18 个真实模型样本。它衡量具体规则遵守行为，不是通用智能基准。

## 1. 测评目标

验证个人助手能否准确读写真实事务、谨慎保存记忆、稳定采用已授权方法，以及在折叠、断流、停止和重启后保持可核对状态。最新范围以 S18–S22 为准。

## 2. 数据集与任务范围

### 2.1 离线与浏览器

后端脚本客户端隔离模型外部波动，断言数据库、事件、确认状态与调用载荷。浏览器连接真实 API 和调度器，但对话模型仍为替身。

### 2.2 真实模型

使用隔离数据根目录，记录实际模型、版本、工作区指纹、完整响应、工具结果及失败样本。历史 P5 数量不足以得出总体效果提升。最新人格与本轮记忆仍待新增真实模型专项。

## 3. 单题执行流程

```text
冻结源码/配置/案例 → 创建隔离数据 → 实际 Agent 请求
  → 收集原始回复/工具调用/数据库 → 判据核对 → 保存成功及失败样本
```

重复尝试必须单独计数，不能只留下成功的一次。调用失败、时间超限、测量完整性与业务未通过分别报告。模型评测成本与调用次数单列。

## 4. Pass@1

若采用 Pass@1，必须事先冻结判据，每个案例仅一次轨迹：`通过案例数 / 总案例数`。本项目目前没有可公布的 GAIA/HLE Pass@1。

当前报告主要使用各层判据通过数、规则命中率、重复写入数、检索载荷、记忆误保存与后处理状态。模型评价、单元测试通过率和部署健康不能混成一个指标。

## 5. 当前项目测评结果

| 验证范围 | 已有结果 | 证据 |
|---|---|---|
| 聊天优先版本后端 | 全量 599 项；随后新增星期订阅测试通过，日历专项 15 项 | [CF 验收](../evidence/CF-acceptance.md) |
| Vue / 类型 / 构建 | 48 项，生产构建通过 | [CF 验收](../evidence/CF-acceptance.md) |
| 隔离 Chromium + 真实 HTTP | 13 组流程，0 页面异常；模型为脚本化替身 | [CF 验收](../evidence/CF-acceptance.md) |
| 既有真实模型 | R4 运行时 19/19、核心演示 24/24 | [R4 验收](../evidence/R4-acceptance.md)，属于较早版本 |
| Skills 三条件对照 | 共 18 个真实模型样本；并非稳定提升结论 | [P5](../../evals/README.md) |

当前版本没有 GAIA/HLE 成绩。不得把其他项目的百分比换名后作为 MellowDay 的结果。最新记忆授权、人格演化的真实模型长期质量仍待专门评估；测试通过不等于语义判断总是正确。

历史 P5 的规则命中：

| 条件 | 开发案例 | 保留案例 |
|---|---|---|
| 关闭 Skill | 2/3 | 0/3 |
| 固定 Skill | 1/3 | 3/3 |
| 学习后 Skill | 2/3 | 3/3 |

三臂的测量完整性各 9/9，不代表回复全部遵守规则。不能据此宣称学习组稳定优于固定组。

## 6. 会话记忆折叠对照

当前有折叠后继续、重启恢复、完整 trace 和工具原文的程序/浏览器证据。尚无当前版本开启/关闭折叠的大样本因果对照，不能声称特定百分点提升。

后续应固定同一批长对话，分别测量开启/关闭折叠的任务完成、参数正确、原文可取回、请求/token 与耗时。保留失败记录，并将记忆提取和会话折叠分开测量。

## 7. 结论

现有证据支持工程流程可以运行，不证明长期人格一致性、零误记忆或普遍能力提升。复现入口：

```powershell
python -m pytest -q
npm --prefix frontend run test -- --run
npm --prefix frontend run build
python frontend/tests/browser/acceptance.py --output .local-planning/browser-review
```

历史真实模型对照见 `evals/p5_compare.py` 和 [R4 复现说明](../evidence/R4-acceptance.md)。它们会调用模型，应在隔离数据下运行，不改写已归档证据。
