# MellowDay 从 0 到 1 学习了解项目

**怎样让个人助手保持一致的角色、谨慎记忆、可靠处理日程，并从反馈中改进方法？**

本文从实际网页请求开始解释当前实现。

## 1. 项目定位

MellowDay 是单用户、单角色、以聊天为主要交互方式的个人助手。日程、提醒、待办与笔记通过工具真实落库；人格、记忆和 Skills 各有独立边界。日常互动由用户发起，仅明确提醒和主动订阅产生定时消息。

## 2. 为什么还要做它

用户不应为了让助手记住事实、沿用方法、说明日程而维护多个主页面。MellowDay 将管理入口收进设置，把日历作为侧栏，同时保留透明的 Python 运行时：

- agent loop 和工具结果反馈。
- 本轮记忆授权与跨会话召回。
- 核心人格与可变表达规则分离。
- Skills 检索、反馈学习和版本记录。
- 会话恢复、上下文折叠和完整原文。
- 浏览器关闭后仍能持久投递的明确提醒。

## 3. 代码在解决什么问题

```text
用户输入 → Vue 对话页 → POST /api/chat/{session_id}
  → SessionRegistry：会话串行、配置刷新、确认与事件通道
  → Agent.chat：核心人格 + 可变表达规则 + Skills + 已保存事实
  → 模型返回文本或 tool call
  → 产品工具白名单 → 业务工具 → SQLite → tool result
  → 模型继续回答 → 会话保存
  → 当前轮记忆评估 / 人格适应 / Skill 学习收尾 → done
```

后台 `ScheduleService` 独立投递明确提醒和订阅，网页关闭时仍保留未读。Skill 学习使用上一轮窗口与本轮反馈；记忆与人格提取使用当前原文，不能混为同一条学习链。

## 6. 它和 Coding Agent 的区别

产品定位是个人助手。它沿用模型工具循环、技能学习、压缩与会话恢复，但不提供编程工具工作台。MCP、Plan Mode、产品子 Agent 均在网页入口禁用；开发时的多 agent 分工不是产品功能。

## 7. Skills

Skills 保存“这类事情以后怎样处理”，如查询指定区间日程后按时间列出。用户事实归记忆，角色口吻归人格。

Skills 通过 `<data>/skills/<name>/SKILL.md` 存储。网页按当前请求词项检索，目前只注入名称、描述与触发条件。规则正文自动投递仍有缺口，不能把技能存在当作模型已采用完整方法。设置中可编辑、停用、恢复与回退版本。默认 `calendar-conversation` 在启动时安装一次，用户停用后不会在下次启动强制重装。

## 8. 自进化

MellowDay 的 Skills 自进化不是“让模型随便改自己”。

它的做法更像一个可审计的闭环：

```text
本轮任务 + assistant 输出
  -> 保存 pending window
下一轮用户反馈
  -> 合并证据
  -> 抽取候选 Skill
  -> 检索相似 Skill
  -> 决策 add / merge / discard
  -> 写入或演化 SKILL.md
  -> 记录 provenance / history / usage
```

这么做是为了避免：

- 把一次性内容误写成长期规则
- 把隐私和临时参数沉淀进能力
- 把幻觉当成经验
- 让技能越积越多但不可控

## 9.长程任务

长对话会出现上下文增长、工具结果膨胀、状态遗失和重启恢复需求。运行时通过 session 保存、工具原文外置、`compact_context` 与结构化 folding 处理。

折叠状态服务于继续对话；完整展示历史与执行 trace 独立保存。它不会触发历史记忆挖掘。

## 10. 权限边界

产品模式在 `_execute_tool_call()` 的分发前检查工具名，未授予工具返回 `tool_not_available`。MCP 首次连接被跳过，Plan 切换无效，网页不提供 Shell、文件编辑、`agent`、`skill`/fork 或手动 `skill_create` 工具。

后台 Skills 检索与学习仍运行；它们和模型可调用工具是不同入口。可逆业务操作走类型校验和操作记录，记忆/Skill 提案走各自授权协议。Skill 自动授权评估完整变更，而不是截断预览；不确定时进入确认。

这些边界是应用层能力限制，不是操作系统沙箱。应用当前没有账户鉴权，Compose 默认仅绑定 `127.0.0.1`，不应直接公开到公网。

## 11. 通用扩展方式

扩展任务方法优先在设置维护 Skill；新增真实业务能力需要在业务模块定义工具、验证参数、接入执行器并补充测试。不能靠 Skill 文本授予新权限或自动建立订阅。当前版本不提供 MCP 或子代理配置入口。

## 12. 介绍

**MellowDay 是把聊天、个人事务、有限人格适应、已保存记忆和可学习任务方法结合起来的本地个人助手。**

它通过 Vue/FastAPI 提供交互，通过 Agent 运行时执行工具，通过 SQLite 与文件保存可核对状态。
