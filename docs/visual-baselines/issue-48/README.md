# Production Web App visual baselines

These five Chromium captures are the bounded visual review set for issue #48:

- `sky-desktop.png` — 1200×780, Sky
- `night-desktop.png` — 1200×780, Night
- `minimal-narrow.png` — 520×640, Minimal
- `appearance-narrow.png` — 520×640, Appearance dialog
- `recent-conversation-drawer.png` — 880×780, recent-conversation drawer

The captures use reduced motion and browser DPR 1. They are not evidence for
real Desktop Shell behavior or Windows display scaling, which remains assigned
to later Desktop Shell acceptance.
