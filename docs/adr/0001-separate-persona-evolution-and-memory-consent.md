# 区分人格演化与记忆保存的授权

单一角色分为核心人格和可变人格：核心人格由用户维护名称、身份背景、基本性格、关系定位、边界及基础示例；可变人格以场景回应规则、表达习惯和少量示例为主体，允许有限幅度的自动演化，无须逐次请求用户批准。临时请求不自动持久化，自主演化不得改变身份、关系定位或虚构身世；每次局部修改同时受单次预算与相对核心和基线的累计偏移检查。此决定不表示人格演化已经实现。

用户明确要求记住的信息直接保存并回执；系统自行发现的记忆候选须经用户批准才保存。两者采用不同授权规则，避免自动人格演化成为绕过记忆确认的入口，也避免每次角色适应都打断聊天。任务 Skills 中用户明确给出的长期方法直接视为授权并回执，系统自行归纳的新增或修改先展示差异并确认；学习不能扩大工具权限或隐式创建定时任务。

复用现有技能学习的提取、合并、版本和回退机制，但人格拥有独立存储和更新接口，不建设完整世界书。来源以用户反馈为主，没有充分证据则不更新；更新在本轮回复后处理，下一轮采用新版本。前端提供安静的变化记录、撤销、暂停、锁定及重置；同一证据不能在撤销后立即生成相同变化。具体阈值通过实现与行为测试调优。
