| 级别 | 含义 |
|---|---|

## 并行与交接约束

- 最多三个实施单元同时工作；主 agent 负责接口契约、集成与阶段判定。
- **同一文件同一时间只允许一个单元写入。** `runtime/agent.py` 与 `web_app/service.py` 是热点文件，跨 issue 共用时必须串行，或由其中一个单元代为修改。
- 子 agent 不递归派生、不提交、不推送、不改原目录；仅编辑分配路径。
- 每批有具体交付和测试；接口改变先通知主 agent，由主 agent 更新 CONTRACTS.md 后其他单元才跟进。
- 上下文压缩后先读本文件、任务板、接口契约、最近检查点，再检查工作区。
- 失败先修复本批，不无限重试；不得将离线测试写成真实模型通过。
