# S18 聊天优先的个人助手：产品范围收口

状态：已记录讨论中确认的产品决定；尚未实施。此文优先于旧规划中冲突的后续目标，不改变历史验收事实。

## 交互与范围

- 单用户、单角色、桌面浏览器，聊天是主界面；人格、记忆、Skills、模型等集中进入设置子菜单。
- 日历保留固定入口及聊天唤起的侧栏，按常规日历提供可视化日程查看和编辑。具体组件与接口在实施规格中确定。
- 不做独立今日概览、每日回顾、不以自然陪伴为验收目标，不做自行决定的主动问候。
- 不做 MCP 接入、Plan Mode 或产品内部多代理功能。实施过程可使用并行开发代理。
- 保留当前实际运行时主链、业务工具、会话、上下文与技能学习机制；不通过另造运行时替代适配。

## 人格

- 唯一角色分核心人格与可变人格。核心由用户编辑名称、身份背景、基本性格、关系定位、交流边界和基础示例。
- 可变人格保存有证据的场景回应规则、表达习惯与少量示例；自动有限演化，无须逐次批准。
- 临时请求只影响当前交互；没有充分证据则不更新。助手自己的回复不作为独立认可证据。
- 演化使用局部更新，受核心约束、单次预算及累计偏移检查；不自主增加身世或改变关系定位。
- 复用既有学习基础设施，使用独立人格存储及写入接口；不建设完整世界书。
- 每轮按需组装核心与少量相关可变规则；人格不修改事实、工具权限或执行结果。
- 在设置中提供版本、撤销、暂停、锁定和重置；默认安静生效，不弹审批框。

## 记忆

- 仅对活动对话的当前一轮判断是否生成记忆，不扫描旧聊天、旧摘要或跨会话历史。处理完的轮次不再回头评估。
- 提取对象是具有未来复用价值的稳定事实或偏好；不保存所有事实，不默认保存临时情绪、假设、引用、助手推断或已有日程副本。
- 明确要求记住直接保存并回执；自动候选先弹出轻量确认，批准才保存。界面可以亲切，但必须区分候选与已保存。
- 保存的记忆跨会话使用，可在设置中查看、修改、删除；不专门建设聊天遗忘流程。
- 已保存记忆可用于回答召回，以及候选去重/冲突检查；不成为生成新候选的事实证据。
- 删除、拒绝后不重新处理原轮。后续用户重新表达属于新一轮证据，可按同一授权规则处理。
- 当前轮上下文不足以解释指代时，不借历史补造持久事实；可以不产生候选或在必要时澄清。

## Skills

- 人格、用户事实和任务方法分流，不因一条反馈生成多份重复状态。
- 用户明确给出的长期任务方法视为授权并回执；系统自行总结的技能新增或修改展示差异，确认后生效。
- 学习不扩大工具权限，不隐式创建订阅或定时任务。
- 日程汇报可由 Skill 组织查询和呈现；时间调度、持久消息与去重由确定性服务承担。

## 日程与定时消息

- 支持明确提醒及用户主动订阅的定时汇报，不自行发起问候。
- 日程提醒独立气泡展示，可定位到日历进行编辑和进一步查看。
- 订阅汇报通过气泡提示，在关联会话查看正文；默认关联创建订阅的会话，不插入无关当前聊天。
- 接收会话删除后暂停订阅，允许在日历相关入口重新指定会话。
- 网页关闭无需外部推送，后端生成持久未读消息，下次打开可查看。
- 后端停机后，过期提醒汇总，订阅只补最新一期。

## 工程落点与验收原则

以下为实现约束，不宣称已有实现：

- 记忆评估以会话与轮次标识建立持久处理状态；失败重试必须幂等，不把重试变成再次挖掘。确认操作不得重复保存。
- 记忆候选与人格演化不同授权；人格自动写入不能成为未批准用户事实的旁路。
- 数据迁移保留用户记录；移除旧入口不等于删除旧数据。旧今日页面与旧 S16 目标按新范围替代。
- 原 S14 产品子代理适配不列为本轮交付前置。既有无关源码的保留/裁剪按影响分析处理，不额外承诺全面重写。
- 提醒持久化、重复触发去重、订阅暂停、时区与日历区间需要真实行为验收。
- 记忆需要验证仅本轮提取、拒绝不重提、删除不重建、恢复不重复写入、已保存记忆仍能召回。
- 人格需要验证核心不可写、多次小修改不累积越界、来源可追溯、撤销不立即重学。

实现接口、存储迁移、组件选型、原子任务与并行文件归属由后续工程规格细化，不新增产品范围。
