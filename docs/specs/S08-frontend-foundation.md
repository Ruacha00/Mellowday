# S08 工程、主题与应用导航

目标：独立 Vue/TS/Vite 工程，保留 MellowDay 的轻柔主题、对话主工作区、五个产品导航和最近会话。四个固定主题与可调简约主题均可本地持久化；原素材授权随项目保存。

输入：原产品设计资产和当前 HTTP 契约。输出：可构建的 `frontend/`，hash 路由，桌面侧栏/移动抽屉，中文可访问控件。字体与装饰本地加载，不引入桌面窗口控制的无效按钮。

验收：

- `npm ci`、`npm run check`、`npm test -- --run`、`npm run build` 可复现；锁文件入库，dist 不入库。
- 路由刷新、浏览器前后退、导航折叠、Escape 关闭抽屉、焦点恢复和主题刷新保留正确。
- 390/768/1440 宽度无全页横向溢出；五主题有清晰文字/焦点对比；减少动态效果设置有效。
- 请求失败与未知接口能正确显示，危险 Markdown 不执行；密钥不写本地存储。

排除：SSR、桌面壳、外网字体、多后端切换。公共文件、包管理与素材由主 agent 独占。
