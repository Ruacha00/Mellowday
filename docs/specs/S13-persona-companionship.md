# S13 单一人格与陪伴

目标：陪伴与事务同等重要。普通聊天先回应用户，不自动生成计划；人格只影响聊天表达，不改变权限、真实结果或中立管理界面。

## 当前交付

- 设置页管理单一人格：称呼、身份、性格、说话方式、关系定位、交流边界。
- 独立本地 persona.json，原子替换；没有模型可调用的人格写入工具。空白配置使用默认人格，损坏文件报错且不覆盖。
- GET /api/persona；PUT /api/persona 接收完整配置，拒绝未知字段、非字符串和超长值。保存后下一轮及恢复会话采用最新配置，不改写历史消息。
- 人格以有界 JSON 数据加入主对话提示词。权限、事实真实性和当前用户意图优先；不向学习提取器注入人格。
- 闲聊、短暂情绪、玩笑不自动成为事实；长期事实与工作流程仍分别进入 Memory 和 Skills。模型不能通过学习改变人格文件。
- 暂不包含主动问候、通知调度、人格槽位或关系等级。

## 验收

1. 修改、刷新、进程重新读取仍保留配置；已有会话下一轮更新，历史保留。
2. API 非法输入、损坏文件和写入失败不报告成功、不破坏原文件。
3. 前端失败保留草稿，可重试；载入失败不能保存空默认值覆盖服务端；离开页面忽略迟到响应。
4. 真实模型案例：疲惫闲聊、只想倾诉、临时情绪、明确建待办、记住偏好、长期流程学习、拒绝危险变更、人格越权文本。分别核对语言与实际状态。
5. 脚本测试证明接线与数据边界；不以提示词字符串测试或模拟模型证明陪伴质量。
