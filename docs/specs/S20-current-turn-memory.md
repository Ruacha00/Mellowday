# S20 本轮记忆与学习权限

上位范围 S18。记忆提取只处理本轮用户原文；不传历史、折叠摘要或召回内容。显式记忆直接保存回执；自动候选由用户确认。SQLite 持久轮次评估和候选状态，不重评已完成轮次、不因拒绝/删除重建。去重冲突可读取已有事实，但不得据其产生新事实；含糊指代不依历史补全。

主模型历史仍可用于正常回答，但记忆写工具必须通过本轮候选验证与授权门，不能因模型调用了工具就绕过确认。已有事实召回保持原路径。候选确认前版本复核；同轮多次调用只处理一次。取消、断连不迟到落库。设置页人工编辑沿用记录接口，不受聊天提取限制。

自动候选用现有 Web 确认事件，回执区分已保存/未保存。明确长期任务技能指令仅在内容与当前证据相符时视为授权，其余技能持久变更继续确认；不扩大工具或调度权限。

根 agent 拥有 service.py、app.py、runtime/agent.py、personal_assistant/tools.py 的集成修改。测试覆盖旧信息诱导工具写入拒绝、本轮显式/自动/拒绝/删除/恢复、并发确认、正常召回。
