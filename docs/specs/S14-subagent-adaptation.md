# S14 子代理执行适配与隔离

状态：规格完成，运行时修复与验收尚未完成。子代理不作为已交付的完整业务能力；本规格不开放新的默认入口。

## 目标与边界

保留现有 Agent 的 fork-return、独立上下文和结果汇总机制，使技能 fork 与 agent 工具使用同一套子代理构造和执行约束。子代理能在父会话授权范围内读取或操作 MellowDay 业务，不因创建新实例丢失模型配置、事实来源、确认通道或预算。

本阶段不提供自主后台代理、递归代理树、跨会话委派、自动 MCP 授权或并行写入。首先提供单层、受限、可取消的执行；子代理默认只读，写操作需要显式执行策略与父会话确认链支持。

## 已确认的源码缺口

检查入口：`runtime/agent.py` 的 `_execute_skill_tool`、`_execute_agent_tool`、`_execute_tool_call`、`_inject_recalled_facts`，`runtime/subagent.py`、`runtime/tools.py`，以及 `web_app/service.py` 的 `build_agent`。

| 缺口 | 现有行为 | 必须达到的行为 |
| --- | --- | --- |
| 执行依赖丢失 | 两个创建路径均未传 `tool_executor`、`fact_provider`、`confirm_fn` | 统一构造；传受工具范围限制的业务执行器、只读事实来源和父会话确认代理 |
| 事实召回被跳过 | `_inject_recalled_facts` 遇到 `is_sub_agent` 直接返回 | 子代理按任务检索允许的 active 事实；不能仅补构造参数便宣称完成 |
| 模型配置不一致 | 仅复制 model 和 OpenAI base URL，未复制显式密钥、Anthropic base URL、thinking | 复用有效配置或受控客户端依赖，不重新依赖环境变量；日志及事件不含凭据 |
| 工具集合错误 | agent 路径从静态运行时定义取工具，不能读取父代理业务工具 | 从父代理有效工具集合取交集，并叠加子代理类型及任务限制 |
| 只读未强制 | explore/plan 仅限制描述；`check_permission` 不按 plan 拒绝业务写入；执行入口也不校验工具是否已授予 | 执行边界验证工具资格及副作用；模型伪造工具调用也不能写入 |
| 递归未封闭 | skill fork 默认仍含 skill；显式 allowed-tools 可含 agent；自定义代理白名单也可含 agent | 所有入口强制单层；子代理遇到再 fork 或 agent 调用必须拒绝 |
| 预算丢失 | 子实例无 `max_turns`/`max_cost_usd`；仅成功返回后汇总 token | 共享或预留父预算，有限子执行上限；失败和取消也记账 |
| 生命周期未统一 | 两条路径各自捕获普通异常；`chat` 吞掉 CancelledError 后 `run_once` 仍返回普通结果，没有取消状态 | 父取消传播、确认撤销、客户端清理和事件闭合在同一执行封装中保证；取消不得被报告为成功 |

重要限制：当前 `skill_create`、`skill_evolve` 的权限检查仍要求确认；不能仅因子实例使用 `bypassPermissions` 就声称它们已经绕过确认。已证实的问题是确认依赖未传入、只读模式未强制以及递归入口不完整。MCP 在子代理中跳过初始化；本阶段明确不给子代理 MCP 能力，不能把名称传入当作执行能力。

## 执行契约

1. **授予范围**：子工具集合等于父可用工具、任务允许工具和子代理类型工具的交集。未知类型、未知工具及非法白名单返回明确错误；空白名单表示零业务工具，不能解释为全部开放。`agent`、再次 fork、计划模式切换和 MCP 在子代理中拒绝。受限 `read_tool_result` 保持独立会话引用校验。
2. **只读范围**：explore/plan 与默认子执行策略只允许明确登记的业务查询、事实读取及当前时间。技能正文可读取，fork 不能递归执行；上下文折叠仅可改变子执行的临时上下文及受控运行记录，不得修改业务记录、Skills 或人格。未知副作用工具默认拒绝。
3. **确认范围**：允许写入的显式任务也不能扩大父权限。持久行为变更沿用父会话的一次性确认令牌；拒绝、超时、断线或会话删除均终止该写入。不能共享父代理的“已确认”缓存，不能以子代理提示词代替真实确认。
4. **事实范围**：事实来自同一 Store 的只读适配器，只纳入 active 记录；不把父聊天全文或全部事实库无条件复制给子代理。过期、删除或更新的事实不因子上下文延续而重新成为权威；确认写入前重新核对必要的记录版本。事实适配器不暴露用于迁移记忆的写入 hook。
5. **预算范围**：定义独立的子执行最大模型调用数与墙钟超时，即使父 `max_turns` 为 null 也不能无限运行。父有限预算耗尽时禁止启动；每次模型调用前检查剩余额度，usage 返回后记账；正在执行的一次调用允许产生有记录的预算超额，不能声称硬性费用封顶。首版同一父会话最多一个活跃子执行，避免并发重复消费同一余额。
6. **取消与结果**：父停止、连接关闭或会话删除时取消并等待子执行及确认，禁止迟到写入、孤儿任务和会话文件复活。成功、失败、预算退出、超时、取消均有可区分状态；返回文本不能把失败说成完成。累计 token 恰好一次，资源在 finally 收尾。
7. **上下文与追踪**：子上下文独立；只返回完成事项、观察依据、未完成事项和消耗。父会话持有可核验的执行状态；折叠不能把待确认写入变成已执行，也不能把子推断自动写入 Memory、Skills 或人格。子事件附执行 ID 与父会话关联，不泄露密钥。

并行安排：SA02 与 SA03 可按模块边界并行，SA04 与 SA05 在公共构造接口稳定后并行。`agent.py` 是共享写入点，必须指定单一负责人整合，不能让多个代理同时改同一函数。每个任务回报修改文件、测试命令、已知限制与下一依赖；中断后从这些记录恢复，不重新扩大范围。

本规格独立于 S13 人格配置的产品交付；如 S13 修改提示词构造或 `agent.py`，以接口约定串行合并。子代理无需继承陪伴人格来完成业务检索，也不得改变人格文件。

## 必须执行的回归

- 对 `agent` 与 `skill(context=fork)` 两条入口都执行以下用例；不能只测试子代理构造参数。
- 使用临时 Store 建立待办和事实，子代理真实调用获授业务读取工具并返回实际记录；未获授工具返回拒绝且 Store 无变化。
- OpenAI 兼容及 Anthropic 配置均使用显式端点/密钥，设置冲突环境变量，验证使用父配置且事件、异常文本与持久日志无凭据。
- explore/plan 模型伪造 create/update/delete、skill_create/evolve、MCP、agent 调用；验证全部拒绝。用 fork 技能诱导递归也必须失败，不能只依赖工具 schema 隐藏。
- 空白名单、未知工具、自定义代理声明 agent、父代理未授予的工具均不扩大权限；默认 agent deferred 状态不被全局激活污染到其他会话。
- 事实读取前后更新、删除、过期；验证新的读取不会继续当作有效事实，并验证 Memory/Skills/人格没有隐式写入。
- 允许的确认操作覆盖批准、拒绝、超时、重复令牌、断线及会话删除，检查实际持久状态和 SSE 事件，不仅检查回复文字。
- 假模型持续要求工具调用，验证子调用次数有限；父额度耗尽不启动；异常和取消消费不漏记、不重复记；并发第二子执行按明确策略拒绝。
- 父取消发生在模型流、工具等待和确认等待三个位置；无孤儿任务、迟到写入或被删除会话复活，客户端关闭可验证。
- 大结果只通过自身引用取回；跨会话引用拒绝；折叠后保持已完成/待确认/失败区分，父对话能继续。
- 跑既有运行时、事实召回、Skills 学习、权限确认、并行工具、Web 会话生命周期测试。真实模型只做有上限的检索及需拒绝任务，作为行为补充，不替代确定性权限测试。

完成 SA07 前，对外材料只描述“保留受限扩展机制，业务子代理适配尚未验收”，不宣称完整多代理业务能力。
