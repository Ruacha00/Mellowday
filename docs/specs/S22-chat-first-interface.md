# S22 聊天主界面与设置子菜单

上位范围 S18。主导航只强调聊天、日历入口、设置；人格、记忆、Skills、模型、外观、历史诊断及记录管理放设置子菜单。移除今日独立功能入口，旧路由重定向不丢数据。

桌面日历侧栏可由固定按钮或 calendar_open SSE 事件唤起。采用成熟开源 Vue 日历组件或具有等价行为的实现，展示月/周/日、点击查看创建编辑、时间区间、全天、重复、提醒，单次/系列编辑。后端接口见 S21。没有外部账户同步或移动端新增范围。

提醒独立气泡，拉取持久未读消息；点击事项打开日历详情，订阅跳关联会话。关闭/已读不等于完成日程。暂停、错误、空态和未配置模型均明确呈现。

人格核心与可变规则管理依 S19，包括来源/历史、锁定/撤销/暂停/重置。自动记忆确认沿用既有确认协议，柔和文案不模糊写入状态。

前端负责人独占 frontend/，负责 typecheck、单元测试和构建；根 agent 做最终浏览器交互验收。后端接口变更先更新规格再通知，避免双向猜测。
