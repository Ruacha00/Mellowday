# 对照评测

`p5_compare.py` 提供三条件对照评测。行为命中率与测量完整性分别记录。

使用固定开发案例调试，冻结后运行不同日期、不同事务的保留案例，并对比三组条件。

```bash
python evals/p5_compare.py --samples 3 --json-out evals/reports/p5-new-run.json
```

每臂使用独立进程与隔离数据目录。退出码 0 表示测量完整性成立，不表示每个回复均遵守规则；样本失败保留在报告的 `failures` 字段。

| 条件 | 说明 |
|---|---|
| 关闭 Skill | 不检索任何工作流程规则 |
| 固定 Skill | 使用人工写定的规则 |
| 学习后 Skill | 使用从用户反馈中学习并版本化的规则 |

三组使用相同的模型参数与初始数据。指标包括规则遵守率、误学习率、检索相关性、事务参数正确率、重复写入数、
上下文折叠后的任务连续性、请求次数与 token 使用；每个比例必须写明分母。

评测必须记录源码版本与工作区哈希、模型实际标识、案例、原始响应、工具调用与数据库结果，不预填提升比例。

记忆评测与 Skill 评测分别记录，完整业务流程另计。
